# dev-skills
一些这里抄抄，那里抄抄的skills，主要用于开发和工作。有的可能经过改写，有的可能没有。

主要适配Claude Code。工作流详情见[AGENTS.md](AGENTS.md)

如果使用这个工作流，建议的项目约束：
```markdown
- 创建新 Git 分支前先征得用户同意；不得擅自提交、推送或覆盖用户已有改动。
- 需求文档在 `docs/requirements/`。
- 设计文档在 `docs/specs/`，设计文档是项目文档的唯一事实来源，需求文档以及其他文档不是。也只有`docs/specs/`会随代码提交到repo，其他文档都应被忽略。
- 设计文档不得包含 gitignore 中忽略的文件。
- 文档冲突时以较新的带日期文档为准，再结合当前可执行代码和配置核对。
```
